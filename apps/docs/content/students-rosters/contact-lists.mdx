# Family contact lists

The **Family Contact Lists** screen (`/admin/contacts`) answers the question "who
should I be emailing about this?" Pick an audience, copy the addresses, and paste
them into Gmail — no digging through past seasons or old inbox threads.

<Shot slug="family-contact-lists" caption="The Family Contact Lists screen." />

## Pick an audience

The **Audience** dropdown offers four ways to slice the families:

| Audience | Who it includes |
| --- | --- |
| **A semester** | Every family with a student enrolled in that term |
| **Recently enrolled** | Every family who enrolled within the last one, two, or three years |
| **A single class** | Just that class's families |
| **All families of all time** | Everyone in the system |

For **A semester** and **A single class**, a second dropdown appears so you can
choose which one. For **Recently enrolled**, choose the time window.

## Primary contact or every guardian

By default each family contributes one address — the primary contact on the
student's record.

Turn on **Include every guardian's email** to also pull in second parents and
other guardians listed on the student. Use it when you want both parents to see a
message; leave it off when one address per family is enough.

## Read the count before you send

Above the list you'll see how many addresses the audience came to, and a note
explaining anything that was adjusted:

- **Duplicate addresses collapsed** — siblings share a parent, so the same address
  would otherwise appear more than once. Each address is listed exactly once. The
  count reflects addresses shared *between students*; a parent listed twice on the
  same student isn't counted as a duplicate.
- **Students with no email on file** — those students couldn't be reached and
  aren't in the list. If the number surprises you, it's worth checking those
  records.

Each row shows the contact's name, their address, and which students they're
attached to — so if an entry looks unexpected, you can see why it's there.

## Copy into Gmail

Click **Copy for Bcc**, then paste into the **Bcc** field of a new Gmail message.

> Always use **Bcc**, never **To** or **Cc**. Addresses in To or Cc are visible to
> every recipient, which shares families' contact details with each other.

Gmail turns the pasted text into individual recipients automatically.

## Save it as a reusable Gmail label

Copying works for a one-off message, but you have to redo it every time. To make
an audience reusable, download it once and import it into Google Contacts as a
**label** — after that you type the label's name into Bcc and Gmail fills in
everyone.

Click **Download CSV**. The screen tells you the label name it will use (for
example *Fall 2026 Families*), and the file is named to match.

Then, in [Google Contacts](https://contacts.google.com):

1. Click **Import** in the left sidebar.
2. Choose **Select file**, pick the downloaded `.csv`, and click **Import**.
3. The contacts arrive already grouped under the label named on the screen.

From then on, start a message in Gmail, type that label name in the **Bcc**
field, and Gmail expands it to every address in it. This works in the Gmail
mobile app too.

> **Re-importing next season creates duplicate contacts.** Google doesn't
> recognise that it's the same family twice; it adds a second copy. Google
> Contacts offers a **Merge & fix** tool that cleans these up, but it's manual.
> If you find yourself importing the same audience repeatedly, that's worth
> mentioning — there's a way to keep these lists updated automatically that
> doesn't involve importing at all.

### If the list is large

Gmail won't send to more than about **500 outside addresses in a single message**.
When an audience is bigger than that, the screen tells you how many messages it
needs to be split across. Copy the list, then send it in batches rather than trying
to send all at once — Gmail will reject the oversized message.

## When to use this instead of View Emails

[Class forms & contacts](/students-rosters/reports) has a **View Emails** button
that's still the quickest way to grab a single class. Use Family Contact Lists when
you need more than one class at a time — a whole semester, everyone from recent
years, or every family you've ever had.
