# Mountain SOL Staff Help

This is the help site for Mountain SOL **staff**. It covers the two tools you use
to run the school online:

| Tool | What it's for | Start here |
| --- | --- | --- |
| **Admin portal** (the enrollment portal) | Classes, semesters, enrollments, discounts, rosters, and helping families with sign-ups and payments | [Getting Started](/getting-started/admin-access) |
| **Public website** (mountainsol.org, built with WordPress) | The pages, news, photos, staff list and sponsor logos visitors see | [Website basics](/website) |

The two tools have separate logins. Use the left menu to switch between them: the
**Admin portal** sections come first, then **Public website**.

This is **not** a parent-facing site. Families don't read these pages; they reach
out, and you use this guide to help them.

## Admin portal

- **[Getting Started](/getting-started/admin-access)**: how admin access works and a tour of the dashboard.
- **[Class Management](/class-management)**: create, edit, copy, and bundle classes; units, images, schedules.
- **[Semester Setup](/semester-setup)**: semesters, the enrollment-page info panel, banners, and confirmation-email content.
- **[Enrollment & Discounts](/enrollment-discounts)**: view, revoke, and refund enrollments; run discount codes.
- **[Students & Rosters](/students-rosters)**: student info, printouts, email exports, t-shirt counts.
- **[Medic Admin](/medic)**: the separate Medic program admin.
- **[Helping Families](/helping-families)**: answers to the questions families actually ask (for example *"Can I add a class to a registration I already paid for?"*).

## Public website

- **[Website basics](/website)**: what to know before you edit mountainsol.org.
- **[Log in](/website/logging-in)**, **[Edit a page](/website/editing-a-page)**, **[Add a post](/website/posts-news)**, **[Add a photo](/website/photos)**.
- **[Update a class or event listing](/website/class-event-listings)**, **[Fix a link](/website/links)**, **[Update the staff list](/website/staff-list)**, **[Add a sponsor logo](/website/sponsor-logos)**.
- **[Check on a phone](/website/checking-on-a-phone)** and **[What not to touch](/website/what-not-to-touch)**.

## Need help?

Email **david@mountainsol.org** about anything this guide doesn't answer, or to get
access to either tool.
