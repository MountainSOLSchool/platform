# What not to touch

These areas control how the whole site works. One wrong click can take the site
down for everyone. If you think something here needs changing, ask David.

## Don't open or change

1. **Plugins**: don't add, update, turn off or delete any.
2. **Appearance**: Themes, Customize, Widgets, Menus and the Theme File Editor.
3. **Settings**: any of the settings pages.
4. **Users**: don't add or change people's accounts. Ask David.
5. **Tools**, and anything named **Performance**, **Cache** or **Security**, or
   any other menu item this guide doesn't mention.
6. The **Template** box on the right side of a page.
7. **Updates**: if WordPress says an update is available, ignore it. David takes
   care of updates.

## Also please don't

1. Delete published pages, posts or photos. Ask David; often they should be
   archived instead.
2. Change a page's web address (the **Permalink** under the title). Old links
   would break.
3. Paste in code or "embed" code from another website.
4. Put private information on the site: children's full names, addresses, phone
   numbers or medical details.
