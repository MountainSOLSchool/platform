# Update a class or event listing

On the website, classes, camps and events are written on regular pages, such as
the Summer and Fall pages. (The classes families actually enroll in are set up
separately, in the [enrollment portal](/class-management).)

1. Go to **Pages** and open the page for that season or event (see
   [Edit a page](/website/editing-a-page)).
2. Update the dates, times, ages and descriptions.
3. Check every **Register** or **Enroll** link still goes to the right place in
   the enrollment portal. Click it in Preview to be sure.
4. If you change a price, double-check it with David first. Prices on the
   website must match the enrollment portal.
5. Click **Preview**, [check it on your phone](/website/checking-on-a-phone)
   too, then click **Update**.

<Shot slug="wp-season-page" caption="A season page in the editor, with the dates and a Register link." />

## Tips

- When an event is over, don't delete its page. Ask David, and he'll archive it
  so old links keep working.
- Starting a new term? Update the season page's dates first, then the links,
  then the photos.
